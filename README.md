# Microsoft 365 Workflow Automation & Reporting System 
## Overview

This project demonstrates an automated IT request and approval workflow built using Microsoft Forms, SharePoint, Power Automate and Outlook.

The goal of the project is to simulate how an internal Corporate IT team can collect, manage, approve and track employee IT support requests using Microsoft 365 tools.

---

## Business Problem

Many IT requests inside organisations are still handled manually through emails or chat messages. This can create delays, missing information, poor request tracking and limited visibility for the IT support team.

---

## Solution

This workflow provides a structured and automated way for employees to submit IT requests and for managers to review and approve them.

The process uses Microsoft 365 tools to automate notifications, approvals, request tracking and status updates.

---

## Tools Used

- Microsoft Forms
- Microsoft SharePoint
- Microsoft Power Automate
- Microsoft Outlook

---

## Workflow

Employee submits IT request through Microsoft Forms  
↓  
Power Automate flow starts automatically  
↓  
Confirmation email is sent to employee  
↓  
Request is stored in SharePoint List  
↓  
Manager receives approval request  
↓  
Request is approved or rejected  
↓  
SharePoint status updates automatically  
↓  
Employee receives final email notification
